# پوشه تصاویر دسته‌بندی الکتروموتورها (Category Images)

برای قرار دادن تصاویر واقعی دسته‌بندی‌ها، فایل‌های وبپ (WebP) با نام‌های زیر را در این پوشه قرار دهید:

- `electric-motors.webp` : تصویر دسته‌بندی کلی الکتروموتورها
- `electric-motor-single-phase.webp` : تصویر دسته‌بندی الکتروموتور تک‌فاز
- `electric-motor-three-phase.webp` : تصویر دسته‌بندی الکتروموتور سه‌فاز
- `single-phase-cast-iron.webp` : تصویر تک‌فاز پوسته چدنی
- `single-phase-aluminum.webp` : تصویر تک‌فاز پوسته آلومینیومی
- `three-phase-cast-iron.webp` : تصویر سه‌فاز پوسته چدنی
- `three-phase-aluminum.webp` : تصویر سه‌فاز پوسته آلومینیومی
